# Laboratorio 07 - Combinaciones con Python

## Descripción
Desarrollo de actividades y ejercicios sobre
combinaciones utilizando el lenguaje Python.

- 02_itertools.py

- Python 3
- Visual Studio Code (recomendado)

## Ejecución
Abrir la terminal en la carpeta del proyecto
y ejecutar los archivos con:

python 01_actividades.py
